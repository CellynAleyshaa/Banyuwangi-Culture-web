# 🌴 Banyuwangi Osing Culture Archive

Arsip digital modern yang mendokumentasikan kekayaan budaya, tradisi, dan warisan leluhur Suku Osing di Kabupaten Banyuwangi. Website ini dirancang sebagai museum digital interaktif untuk melestarikan dan memperkenalkan budaya Banyuwangi kepada generasi muda.

## ✨ Fitur Utama

- 🌗 **Dark Mode & Light Mode**: Tampilan nyaman dengan opsi tema gelap/terang.
- 🔍 **Search Engine**: Pencarian cepat untuk budaya, tradisi, legenda, dan batik.
- 🖼️ **Gallery Modal**: Tampilan foto interaktif dengan efek zoom dan slideshow.
- 📱 **Fully Responsive**: Tampilan sempurna di Desktop, Tablet, dan Mobile.
- 🎨 **Modern UI/UX**: Desain clean, elegan, dan menggunakan efek glassmorphism.
- 📜 **Scroll Animations**: Animasi halus saat menggulir halaman (Fade, Slide, Zoom).
- 🎵 **Floating Audio Player**: Pemutar musik tradisional khas Banyuwangi.

## ️ Teknologi yang Digunakan

Proyek ini dibuat menggunakan teknologi web standar tanpa framework eksternal:

- **HTML5** (Struktur halaman)
- **CSS3** (Styling, Animations, Glassmorphism)
- **Vanilla JavaScript** (Interaktivitas, DOM Manipulation)
